# 📊 Unemployment Analysis with Python

## 📌 Project Overview

This project analyzes unemployment data in India using Python to understand unemployment trends, regional variations, and changes during the COVID-19 period.

The project follows a complete data analysis workflow, including data loading, cleaning, exploratory data analysis, visualization, regional analysis, and COVID-19 impact analysis.

## 🎯 Objective

The objective of this project is to:

* Analyze unemployment rate data
* Identify unemployment trends over time
* Compare unemployment rates across different regions
* Analyze employment and labour participation trends
* Investigate changes in unemployment during the COVID-19 period
* Extract meaningful insights from the available data

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Jupyter Notebook**

## 📊 Dataset

The project uses two datasets:

* `Unemployment in India.csv`
* `Unemployment_Rate_upto_11_2020.csv`

The datasets contain information related to unemployment, employment, labour participation, regions, and dates.

## 🚀 How to Run
